Dataset
- File: Dataset/college_admission_2500_10_fields.csv
- Records: 2,500
- Fields: 10 (9 input features + 1 target)
- Target: Admission_Chance (continuous value between 0 and 1)
- The dataset is synthetically generated for academic demonstration.

Project structure
- Dataset/                 CSV dataset
- Images of model/         EDA and evaluation charts
- python_code/all code.py  Complete source code
- Reports/final report.pdf Final project report
- Reports/EDA_Report_College_Admission.html Interactive/browser-viewable EDA report
- Model/                   Saved model, feature list, and comparison metrics

How to run
1. Install Python 3.10+.
2. Open a terminal in the project folder.
3. Install dependencies:
   pip install pandas numpy matplotlib scikit-learn joblib
4. Run:
   python "python_code/all code.py"

The script reads the CSV using a relative project path and saves graphs and trained model files in their respective folders.

Important limitation
The data is synthetic and the model output is a classroom demonstration only. It is not a real or calibrated probability of admission to any college.
